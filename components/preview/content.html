Rendered body copy sets its own vertical rhythm, so every block below is separated by the same spacing regardless of the page layout around it.

A heading between two paragraphs

Paragraphs, headings, lists and figures are direct children of .content and are spaced by row-gap rather than by margins on the elements themselves.

  • Blog posts use it inside the article layout
  • Case studies use it inside the case study layout
  • Topic pages use it outside any page layout

Because the spacing lives here, body copy reads the same in all three.
